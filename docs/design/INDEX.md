# デザイン (Claude Design のハンドオフ)

## 設定ウィンドウ (このフォルダ直下)

issue #16 で決めた画面構成と見た目の規則。実装 (#17) はここを正とする。

- `README.md`: 仕様書。末尾の「付録 A」が本文より優先する (タイトルバー、最小サイズ、スクロール、失敗表示、ログの未読など)
- `tokens.css`: 配色・余白・文字のトークン。renderer の CSS はこれを出発点にする
- `*.dc.html`: 参照実装。ブラウザで開いて見た目と寸法を確認する用で、製品コードには取り込まない
- `設定画面レイアウト案.dc.html`: 3 案の比較と採用案 (2a タブ切替型) の全タブ
- `README.md` の「トレイ / アプリアイコン」の節は `app-icon/` のハンドオフで置き換えた (アプリアイコンは赤地の円ではなく「フレーム + 赤丸」)

## アプリアイコンとトレイアイコン (`app-icon/`)

issue #6 で決めたアイコン。アプリアイコンは 5a「フレーム + 赤丸」、トレイは円ひとつで 3 状態 (待機 = 輪、録画中 = 塗り、未ログイン = 破線の輪) で確定。

- `app-icon/README.md`: 仕様書 (寸法、色、サイズ別の描き分け、実装手順)
- `app-icon/build/`, `app-icon/tray/`, `app-icon/svg/`: 納品された PNG と元の SVG。出荷に使う複製はリポジトリ直下の `build/` と `resources/tray/` (トレイの Retina 版は `-2x` を `@2x` に改名してある)
- `app-icon/アプリアイコン案.dc.html`: 確定案と検討過程の一覧 (`preview/` の画像を参照する)。ブラウザで開いて見る用
