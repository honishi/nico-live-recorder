前回 / フレーム案のバリエーション
同じ骨格で 4 通り（反転 / 角丸括弧 + 脈動 / 対角括弧 / 画面入り）
5b の系統を軸に、板の色・括弧の形・要素の足し引きを変えた 4 案。文字なし、色は赤 #d92b2b / 白 / 墨のみ。推奨は 6b。
6a 反転（赤地）
Windows
5a の白黒を入れ替え、赤地に白の括弧と白の丸。赤の面積が最大なので Dock でいちばん見つかりやすく、初回の「赤地 + 白丸」の方向とも地続き。ただし白丸は録画中の赤丸ではなくなるので、トレイとの色の繋がりは弱まる。
16 / 32px は括弧を太らせ腕を伸ばして描き直し
6b 角丸括弧 + 脈動 推奨
Windows
括弧の角を丸めて板の角丸と揃え、赤丸の左右に赤い弧を添えて「今まさに配信中」の脈動を出した。角丸のおかげで括弧が板になじみ、4 案でいちばん Dock の隣人と質感が合う。赤の要素が丸 + 弧の 2 段になるのでトレイとの繋がりも強い。
16 / 32px は脈動の弧を落として赤丸を拡大。括弧 + 赤丸のシルエットは保つ
6c 対角括弧 + 弾幕
Windows
括弧を左上と右下の 2 隅だけに減らし、空いた対角に弾幕を散らした。4 隅版より軽く、弾幕が斜めに流れていく方向が生まれる。赤丸は括弧の内側で線に触れない位置に置き、切り分けられて見えないようにした。
16 / 32px は弾幕 2 本、赤丸を拡大。括弧が 2 隅なので小サイズでは枠として読みにくくなる
6d 画面入り
Windows
括弧の内側にもう一段暗い映像面を敷き、その上を弾幕 3 本が流れる。赤丸は面の中の指示灯として小さく置いた。密度は 4 案で最大で、コメント欄そのものの見た目に近い。赤の面積は最小。
16 / 32px は弾幕 1 本 + 赤丸まで削る。要素が多いぶん小サイズでの損失は最大
並べて比較（右端は前回の 5b）
遠くからの発見しやすさは 6a > 6b > 6c > 6d、密度と作り込み感は 6d > 6b > 6c > 6a。6b を推す理由は、括弧の角丸で板と要素の言葉が揃い、赤が丸 + 弧の 2 段で効いて、16px まで壊れないためです。
候補は candidates/v6-{a,b,c,d}/（1024 PNG 2 種 + SVG 2 種）。トレイの 3 状態は変更なし。
前回 / 添付のフレームをモチーフに
アプリアイコン 3 方向（フレーム + 赤丸 / 弾幕入り / 赤丸主役）
添付の「4 隅のカギ括弧 + 赤い丸」を骨格に。文字は入れない指定なので REC の位置は空けるか弾幕に置き換えています。板は墨 #1e1c20、括弧は白、赤は #d92b2b。推奨は 5b。
5a フレーム + 赤丸
Windows
添付にいちばん忠実な構成。REC の文字を抜いて赤丸を中央に寄せ、括弧の中に収めた。「これから録る範囲」と「録画」が最短で読め、シルエットが単純なので 16px でも崩れない。ニコ生らしさは弱い。
5b フレーム + 赤丸 + 弾幕 推奨
Windows
原案の「赤丸 + REC」のリズムを保ったまま、文字の位置に長さの違う弾幕 3 本を入れた。文字を使わずに原案の構成と情報量を再現でき、括弧が「録画範囲」、弾幕が「ニコ生の画面」を担う。この一式でいちばんバランスが良い。
5c 赤丸主役 + フレーム
Windows
括弧を板の四隅まで広げ、その中に大きな赤丸を置いた。トレイの「録画中 = 塗りの丸」がそのまま拡大されて見えるので繋がりが最も強く、赤の面積も最大。ニコ生らしさは 3 案で最も弱い。
並べて比較（右端は前回の 4a）
3 案とも白の括弧が板の内側で閉じるので、明暗どちらの背景でも輪郭が保たれます。原案への忠実さは 5a、情報量とニコ生らしさの両立は 5b、赤の存在感と小サイズ耐性は 5c。文字を入れて良いなら 5b の弾幕を REC に戻すこともできます（要相談）。
候補は candidates/v5-{a,b,c}/（icon.png 1024 macOS 角丸・外側透過 / icon-win.png 1024 正方形 / SVG 2 点）。トレイの 3 状態は変更なし。
