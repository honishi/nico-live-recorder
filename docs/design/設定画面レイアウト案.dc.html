2a
タブ切替型（1a）— 各タブ
上の状態行・タブ行・下端の情報バーは全タブで固定。タブ側のバッジ（録画 2 / 対象 4 / ログ WARN 1）だけが変わり、開いているタブ以外の異常にも気づける。ライトとダークを並記。
対象タブ
追加欄が常に最上部。フォロー状態は表内で確認し、未フォローは警告バッジ + 表下に理由を 1 行。無効の行は文字色を落として区別。
履歴タブ
新しい順固定。検索 + 配信者 + 状態の 3 つだけ。下端に「n / 全件 · 合計サイズ」と追加読み込み。ファイルを消した行は「削除済」でサイズを —。
ログタブ
時刻・レベル・本文の 3 列を等幅で固定。debug は既定オフのチェックで切替。レベル色は INFO 灰 / REC 緑 / WARN 橙 / ERROR 赤。
設定タブ
保存 / 検知と通知 / アカウント の 3 群。ラベル列 110px 固定でそろえ、影響の説明が必要な項目だけ補助テキストを付ける。保存ボタンは無し（即時反映）。
未ログイン時
対象・履歴は空状態を出し、設定タブのアカウント群がログインの入口になる。タブ自体は塞がない。

状態ごとの見え方
録画中 — 赤の塗りバッジ + 赤み 9% の面 + 赤 34% の枠。カード形式で最上部。数は見出し横に出す。
未ログイン — 状態帯を警告色にし、本文域は「次にやること」1 つ（ログインボタン）と 3 ステップの説明だけ。他の一覧は出さない。
対象が未登録 — 破線枠のプレースホルダに追加欄への誘導文。表ヘッダは出さない。
履歴なし — 表の中に 1 行分の淡色テキスト「録画履歴はまだありません」。枠は保つ。
エラー — 行単位は「中断」バッジ（警告色）+ 理由 + 詳細リンク。恒久的な失敗のみ赤。ログの ERROR は赤、ナビ / 折りたたみ行に件数バッジ。
バッジと表

進行中だけ塗りのピル（丸 + 白文字）。終わった状態は淡色の面 + 同系色の文字で角丸 4。件数は枠つきピル。バッジは 11/600、上下 2px・左右 7px 固定。
表は CSS grid の行。ヘッダ 30px（11/600、面色）、行 36px（compact 30px）、罫線は行間の横線のみ、縦罫なし。時間・サイズ・件数は右寄せ + tabular-nums、タイトルは 1 行省略。行の操作はホバーで出す。

これから載せる機能の置き場所
録画履歴：3 案とも「直近の録画」は今日ぶんだけ表示し、それ以上は独立した履歴画面（1a はタブ、1b は「すべての履歴」、1c はナビ項目）へ。並びは新しい順固定、上部に検索と配信者フィルタ、下端で追加読み込み。行は同じ表規則のまま列だけ増やす（日付・ファイル）。
debug 表示：ログ画面の上端に「debug を表示」チェック。既定オフ、レベルの色は INFO 灰・REC 緑・WARN 橙・ERROR 赤で固定。
最小 760×640 への縮み方：カードは 1 列固定のまま、表は「コメント」→「サイズ」の順に列を落とす。タイトル列は最小 160px。ボタンは常に右端で折り返さない。
