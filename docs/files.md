# 出力するファイルの一覧

このアプリが書き出すファイルは、**設定・状態・ログ** を置く場所と、**録画** を置く場所の 2 か所に分かれます。
録画ファイルを自動で消す処理はありません。ログは退避時に `app.log.1` を上書きし、ログアウト時には購読状態とログインセッションを削除します。

## 設定・状態・ログ (userData)

| OS      | 場所                                                |
| ------- | --------------------------------------------------- |
| macOS   | `~/Library/Application Support/nico-live-recorder/` |
| Windows | `%APPDATA%\nico-live-recorder\`                     |

環境変数 `NLR_USER_DATA` で別の場所に差し替えられます (検証用)。

| ファイル                 | 内容                                                                                    | 書き方                                        |
| ------------------------ | --------------------------------------------------------------------------------------- | --------------------------------------------- |
| `settings.json`          | 設定 (保存先、録画対象、ポーリング間隔、空き容量のしきい値、画面の状態、ウィンドウ位置) | `.tmp` に書いてから置き換え                   |
| `recording-history.json` | 録画履歴 (最大 2000 件)                                                                 | 同上                                          |
| `push-subscription.json` | push の購読状態 (AutoPush の ID と endpoint、復号鍵、ニコニコへの登録状況)              | 同上                                          |
| `logs/app.log`           | ログ (info 以上。「debug を表示」が有効な間は debug も)                                 | 追記。5 MB を超えたら `logs/app.log.1` へ退避 |
| `Cookies` などその他     | ログインセッションやキャッシュ。Electron 本体が作るもの                                 | Electron が管理                               |

ログアウトボタンを押すと確認ダイアログを表示します。確認すると放送開始の監視と進行中の録画を停止し、録画ファイルと履歴の書き込み完了を待ちます。開始処理中の録画も取り消します。その後、Cookie を削除する前にニコニコ側の push 登録と AutoPush のチャネルの解除を試み、`push-subscription.json` と `Cookies` のログインセッションを削除します。通信に失敗してもログアウトは完了し、次回ログインでは新しい push 購読を作成します。設定・録画履歴・録画ファイルは残ります。設定ごと初期化したいときは、アプリを終了してからこのフォルダを削除してください。

## 録画

| OS      | 既定の保存先                             |
| ------- | ---------------------------------------- |
| macOS   | `~/Movies/NicoLiveRecorder/`             |
| Windows | `%USERPROFILE%\Videos\NicoLiveRecorder\` |

設定画面で変更できます。環境変数 `NLR_OUTPUT_DIR` で既定値を差し替えられます (検証用)。

保存先の下に `{providerId}_{配信者名}` 形式の配信者ごとのフォルダ (例: `12345678_配信者名`) を作り、1 放送につき次のファイルを置きます。ID と配信者名はファイル名に使える文字に整え、配信者名が空か取れなければ ID のみ、ID が空か取れなければ `unknown` を使います。既存のフォルダは改名しません。ファイル名は `YYYYMMDD_HHmmss_{providerId}_{programId}` です (例: `20260906_032403_12345678_lv351329587.ts`)。

日時は日本時間の放送開始日時で、端末のタイムゾーンには依存しません。開始日時が取れなければ現在日時、配信者 ID (`providerId`) が取れなければ `unknown` を使います。タイトルはファイル名に含めず、メタデータ JSON と録画履歴に残します。既存の録画ファイルは改名しません。

| ファイル              | 内容                                                                                                           |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| `<名前>.ts`           | 映像 + 音声 (MPEG-TS, h264 / AAC, 最高画質)。録画が途中で止まって再開すると `<名前>_2.ts`, `_3.ts`, … と増える |
| `<名前>.comments.csv` | コメント。BOM・ヘッダー付き UTF-8 の CSV。再開しても最初のファイルに追記し続ける                               |
| `<名前>.json`         | 番組情報と録画結果のメタデータ                                                                                 |

同じ放送を録り直すとき (アプリが落ちて再起動した後など) は、既存のファイルを上書きせず空いている連番を使います。

### コメント CSV

列は次の14項目で固定します。

```text
at,no,content,vpos,rawUserId,hashedUserId,accountStatus,position,size,color,font,opacity,id,liveId
```

- `at` は投稿時刻の日本時間 (例: `2026-09-06T12:34:56.789+09:00`) です。端末のタイムゾーンには依存しません。
- `color` は `white` などの名前、または RGB 値を変換した `#RRGGBB` です。その他の値は取得したまま保存します。
- ヘッダーは英語の列名、データの各フィールドはダブルクオートで囲みます。内部の `"` は `""` とし、本文の改行・タブはそのまま保持します。複数行の本文も1レコードです。
- 数式に見える本文も補正せず保存します。CSV の引用符は文字列型を指定しないため、表計算ソフトの読み込み方によっては数式として扱われます。
- レコード間の改行は LF です。引用符のエスケープは RFC 4180 に倣いますが、CRLF を使う厳密な準拠形式ではありません。
- コメントが0件でも BOM とヘッダーを保存します。再開時は重複して書かず、既存ファイルの先頭が想定する BOM・ヘッダーと一致しなければ追記を中止します。コメント保存が失敗しても映像録画は続行します。
- JSONL の新規保存や形式の選択はありません。過去の `.comments.jsonl` は変換・追記・削除しません。旧形式の履歴がある番組を録り直す場合は CSV を新規に作り、取得できる過去コメントも取得します。履歴のコメント数は新しい CSV の件数になります。

## 開発用スクリプト (手動で実行したときだけ)

| スクリプト                   | 出力                                                                                                                        |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `scripts/record.ts`          | 引数の出力先 (既定 `./recordings/`) に映像・コメント・メタデータ                                                            |
| `scripts/record-comments.ts` | 既定 `./recordings/<lv番号>.comments.csv`                                                                                   |
| `scripts/push-listen.ts`     | 既定 `./recordings/push-state.json`                                                                                         |
| `scripts/e2e-screenshots.ts` | 引数の出力先 (既定 `./recordings/screenshots/`) にスクリーンショット、`electron.log`、隔離用の `userdata/` と `recordings/` |
