NicoLiveRecorder for Windows / macOS

配信が始まったら、
もう録っている。

登録した配信者のニコニコ生放送を自動で検知して、映像とコメントを保存するアプリです。番組 ID や URL を指定した手動録画や、タイムシフトの保存にも対応しています。

macOS 版 Apple Silicon Windows 版 x64

最新版 · インストール手順 · 無料 / オープンソース

01 / DETECT

放送開始を自動で検知

フォロー中の配信者を push 通知と定期確認で見張り、始まったら録画、終わったら停止します。

02 / RECORD

映像もコメントも

取得できる最高画質の映像と、コメントを CSV で保存します。切断されても自動で再開します。

03 / TIMESHIFT

手動録画とタイムシフト

番組 ID や URL を入れればすぐ録画。終了済みの放送も、視聴できるタイムシフトを保存できます。
